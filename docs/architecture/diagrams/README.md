# Architecture Diagrams

This directory contains Mermaid source diagrams for the merged Token-Efficient Agent Harness architecture book.

## Files

- `system_overview_layers.mmd` — system overview layering diagram, including Orchestrator Core, 7 original planes, and Governance & Policy Plane.
- `policy_candidate_lifecycle.mmd` — controlled adaptive policy candidate lifecycle.
- `ca_maturity_gates.mmd` — CA-0 through CA-8 maturity gate progression.

These diagrams are source-of-truth Mermaid files. Rendered images can be generated from them with Mermaid-compatible tooling when needed.
