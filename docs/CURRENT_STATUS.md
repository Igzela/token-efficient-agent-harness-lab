## Current App Capability

The local Harness App (MVP0–MVP8) provides:

- **Repo registry** — register local or remote target repositories.
- **Local target audit** — read-only inspection of harness control files in a target repo.
- **Non-executable planning** — deterministic resource plans with steps, budgets, approval gates, and blockers. Plans are never executed.
- **App-owned plan store** — legacy Harness App resource plans persist in a local JSON file owned by the app; the Rust Agent Control Plane now also persists read-only `WorkflowGraph` plans in SQLite.
- **Plan review workbench** — plan history, summary, comparison, and advisory review actions.
- **Review guidance** — non-persistent advisory guidance derived from stored plans.
- **Portfolio triage** — read-only ranking of stored plans by risk, budget, and bottleneck.
- **Operations diagnostics** — component health, data flow, storage status, recent errors.

The local Agent Control Plane runtime now also provides:

- **SQLite local team state** — app-owned dispatch history, read-only workflow plans, workflow run/node/edge/event/approval state, supervised workspace/artifact state, scheduler feedback, config, team/API-key metadata, audit log, and cost summary.
- **Live local dashboard state** — dashboard reads `/api/v1/dashboard` from the Rust engine instead of fixture rows.
- **Local role boundary** — optional `ACP_REQUIRE_AUTH=1` plus `ACP_ADMIN_API_KEY` enables scoped local API keys; admin-only backup requires `backup:admin`.
- **Export and backup** — `/api/v1/export` exports app-owned state; `/api/v1/backups` creates local SQLite backups only with local auth enabled, `backup:admin`, `confirm_local_backup=true`, and an audit event.
- **Operations and disaster-recovery smoke** — `/api/v1/metrics`, `/api/v1/storage/integrity`, backup verify, restore dry-run, `scripts/acp_ops_check.py`, and `scripts/acp_restore_smoke.py` cover local operational visibility and non-destructive restore rehearsal.
- **Read-only planner API** — `/api/v1/plans` creates canonical `WorkflowGraph` plans with recommendation-only quality/routing/retry/observability advisory metadata and stores them in app-owned SQLite; list/detail endpoints are read-only views of that planning metadata and do not execute or write target repositories.
- **Workflow run API + scheduler** — `/api/v1/workflow-runs` stores workflow run/node/edge/event/approval state in app-owned SQLite. Explicit tick/scheduler paths can execute node-level `NodeExecutor` work in app-owned workspaces. Dynamic scheduler mode routes through `DynamicWorkflowController` so failed nodes can mutate the persisted graph, schedule fix/test follow-up nodes, resume, and complete.
- **Supervised execution runtime primitives** — `NodeExecutor` trait with `CommandNodeExecutor` (shell-metachar rejection, allowlist, no `sh -c`), workflow tick endpoint for node-level execution, workspace directory lifecycle (create/cleanup/quarantine), capture_patch with source manifest diff and secret scan, approval binding with bound fields, integrity validation, and export gate. E2E tests prove command/CLI executor-created files flow through capture → integrity → approval → export. No target repo writes, sandbox/process/container/VM execution, provider calls, push/merge/deploy/apply controls, or default-on execution.
- **SDK access** — TypeScript and Python REST SDKs cover dashboard, dispatch history, read-only plans/advisory metadata, workflow-run metadata, supervised patch metadata, config, team, costs, export, audit, dispatch, and confirmed backup.

## State Boundary

| State | Owner | Writable | Description |
|---|---|---|---|
| Target repositories | User | No (read-only by app) | The app never writes to target repos. |
| App registry | App | Yes | Stores registered repo metadata. |
| Plan store | App | Yes | Stores non-executable resource plans and Rust Agent Control Plane read-only workflow plans in app-owned SQLite. |
| Diagnostics | Derived | No | Computed on each request from app state. |
| Review guidance | Derived | No | Computed from plan store. Not persisted. |
| Portfolio triage | Derived | No | Computed from plan store. Not persisted. |
| Agent Control Plane SQLite | App | Yes | Stores local dispatch history, read-only workflow plans, workflow run state, dynamic graph mutation events, supervised patch workspace/artifact metadata, scheduler feedback, config, team/API-key metadata, cost state, and audit log. |
| Local backups/export | App | Yes | Backup/export operates only on app-owned SQLite state and requires explicit confirmation for backup. |

No app output constitutes execution authority. The human operator remains the final decision-maker.
