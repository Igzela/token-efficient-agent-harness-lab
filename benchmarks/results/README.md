# Benchmark Results

This directory is reserved for curated benchmark summaries.

Do not commit raw traces here. A result committed here must be:

- redacted;
- bounded;
- tied to a scenario id;
- tied to a runtime kind and version;
- tied to a scorecard schema version;
- clear about whether the task passed or failed;
- clear about whether token counts are measured or estimated.

High-volume trace data belongs in app-owned local artifacts or LocalProductStore-backed records.
